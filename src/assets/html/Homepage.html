Web Services API

A production-ready backend platform built with Hono, TypeScript, Bun, and OpenAPI. Designed for scalable web applications with modular routing, authentication, static asset serving, enterprise configuration, and comprehensive API documentation.

Hono TypeScript Bun OpenAPI Swagger UI Zod Drizzle PostgreSQL JWT Cookies Argon2 Biome Vercel Ready

Platform Overview

📦
Modular API
Feature-based architecture with isolated routes, controllers, middleware and services for long-term maintainability.
📖
OpenAPI
Interactive API documentation powered by Swagger UI and modular OpenAPI 3.0 specifications.
🔐
Authentication
Secure email and phone authentication with cookie-based JWT sessions and refresh token rotation.
⚡
Enterprise Ready

Public Endpoints

GET / Application homepage
GET /about Project information
GET /documentation Interactive Swagger UI
GET /openapi OpenAPI JSON specification
GET /health Health monitoring endpoint
GET /app/health API health endpoint
GET /assets/{path} Static assets (CSS, JS, fonts, images)

Email Authentication

POST /auth/email/signup Create a new account
POST /auth/email/signin Authenticate user
POST /auth/email/signout 🔒 Auth required
POST /auth/email/refresh Refresh access token
GET /auth/email/me 🔒 Current authenticated user
POST /auth/email/verify-email Verify email address
POST /auth/email/forgot-password Password recovery
POST /auth/email/reset-password Reset account password

Core Features

📖
OpenAPI Documentation
Modular OpenAPI 3.0 specification with interactive Swagger UI. Every endpoint is documented using reusable schemas and components.
🔐
Cookie Authentication
Secure authentication using httpOnly access and refresh cookies. Automatic token rotation provides seamless user sessions.
📁
Static Asset Serving
Efficient serving of HTML, CSS, JavaScript, images, icons and fonts with proper MIME types and cache headers.
⚙️
Enterprise Configuration
Strongly typed application configuration using Zod validation and a centralized appConfig.
🛡️
Security
Secure headers, CORS, request IDs, validation, rate limiting and centralized error handling built for production deployments.
🚀
Production Ready
Built with Hono, Bun and TypeScript for deployment on Vercel or other modern serverless environments.

Quick Start

bash
# Clone repository
git clone https://github.com/your-username/web-services-api.git

# Install dependencies
pnpm install

# Configure environment
cp .env.example .env

# Generate database
pnpm run db:generate
pnpm run db:migrate

# Start development server
pnpm run dev

# Open API documentation
http://localhost:7164/documentation
